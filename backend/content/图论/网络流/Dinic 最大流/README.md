Dinic 求有向图最大流，适用于点数几千、边数几万的网络流建模题。

## 核心思想

- BFS 在残量网络上分层，只保留 `level[v] = level[u] + 1` 的边，得到分层图；
- DFS 沿分层图一次推到底，正向边减流、反向边加流，反向边就是退流的通道；
- 当前弧 `cur[u]` 记住点 u 已经增广完的边，同一轮里不再重复扫描；
- 重复「BFS 分层 + 多路 DFS 增广」，直到汇点不可达。

## 复杂度

- 时间：一般图 $O(V^2E)$，单位容量图 $O(E\sqrt{E})$，实际远快于上界；
- 空间：$O(V+E)$，每条原边存正反两条。

## 使用与易错点

- 点编号 1-based；多测必须先调 `init(n)`，否则上一组的边还留在 `g` 里；
- 无向边要正反各加一次（各带一条容量 0 的反向边），只加一条会变成单向边；
- 容量与总流量用 `long long`，`llinf` 是 DFS 的初始上限；
- 递归深度等于分层路径长度，点数十万以上时注意栈空间；
- 跑完后残量网络仍然有效，可继续加边增广，也可以用来求最小割的 S 侧。

## 相关模板

- 网络流/最小割：复用同一套 Dinic，只多一步残量网络 BFS
- 网络流/最小费用最大流：把分层 BFS 换成按费用求最短路
