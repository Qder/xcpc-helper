最小割：删掉容量和最小的一组边，使 $s$ 与 $t$ 不连通；由最大流最小割定理，割容量等于最大流。

## 核心思想

- 先跑 Dinic 求最大流；
- 在残量网络上从 $s$ 出发 BFS，能走到的点构成割的 S 侧；
- 所有「S 侧 $\to$ T 侧」且已满流的原边组成一个最小割；
- 代码里的 `side[]` 就是 S 侧，便于输出方案。

## 复杂度

与 Dinic 相同：时间 $O(V^2E)$，空间 $O(V+E)$。

## 常见建模套路

- 割点 / 点权：把点 $u$ 拆成 $u$ 与 $u'$，中间连容量为点权的边；原边 $u \to v$ 改成 $u' \to v$（容量 INF），割拆点边就等于选这个点；
- 最大权闭合子图：正权点 $S \to u$ 容量为权值，负权点 $u \to T$ 容量为 $|$权值$|$，依赖边容量 INF，答案 = 正权之和 − 最小割；
- 二分图最小点覆盖 = 最大匹配（König 定理），最大独立集 = 总点数 − 最小点覆盖。

## 使用与易错点

- 建模用的「不能割」的边要给 `llinf` 级容量，避免被误割；
- `side[]` 会被下一次 `min_cut` 覆盖，需要保存就自己拷一份；
- 输出 S 侧时按点编号升序，方便和暴力对拍；
- 源点必须在 S 侧、汇点必须在 T 侧，这是判定的最低要求。
