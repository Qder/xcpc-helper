SPFA 版最小费用最大流：在残量网络上每次沿单位费用最小的增广路推流。

## 核心思想

- 把费用看成边权，用 SPFA 求 $s \to t$ 的最短路（允许负费用）；
- 沿最短路增广，流量取路径上的最小残量，费用累加 $f \times dis[t]$；
- 反向边费用取相反数，退流时把已经付过的费用还回去；
- 反复「找最短路 + 增广」直到汇点不可达。

## 复杂度

- 时间：$O(F \cdot VE)$，$F$ 为最大流；SPFA 常数小，随机图上很快；
- 空间：$O(V+E)$。

## 使用与易错点

- `init(n)` 清空，多测必调；点编号 1-based；
- 费用可以为负，但不能存在从源点可达的负费用环，否则最小费用无意义；
- 若所有费用非负，可换成 Dijkstra + 势能：维护势 $h[v]$，边权改成 $c + h[u] - h[v]$，每轮最短路降到 $O(E\log V)$；
- 最大流与总费用都可能超过 `int`，统一用 `long long`。
