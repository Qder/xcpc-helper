二维凸包：求能围住所有点的最短围栏长度（凸包周长），Andrew 单调链实现。

## 核心思想

- 所有点按 $x$ 再按 $y$ 排序，先去掉重复点；
- 从左到右维护下凸壳：新点若让栈顶右转或共线就弹栈；
- 再从右到左维护上凸壳，两段拼起来就是完整凸包；
- 叉积 $\le 0$ 时弹栈，等价于丢掉共线点，只保留端点。

## 复杂度

- 时间 $O(n\log n)$（排序主导），空间 $O(n)$。

## 使用与易错点

- 用 `long double` 算叉积：$|坐标| \le 10^6$ 时叉积约 $8\times 10^{12}$，double 够用；$|坐标|$ 到 $10^9$ 时叉积可达 $8\times 10^{18}$，必须 long double 或 `__int128`；
- 重复点必须先去掉，否则叉积为 0 会干扰判断；
- 共线点被丢弃不影响周长；要保留共线点就把 `<= 0` 改成 `< 0`；
- 只有 1 个点返回 0，2 个不同点返回两点距离的 2 倍（退化线段）；
- 输出两位小数用 `fixed << setprecision(2)`，四舍五入由 iostream 负责。

## 常见变形

- 凸包面积：叉积和的一半；
- 旋转卡壳求直径 / 宽度；
- 动态凸包、半平面交。
