后缀数组：把所有后缀按字典序排序，得到 `sa`、`rank` 与 `height`（相邻后缀的 LCP）。

## 核心思想

- 倍增：先按长度 1 的子串排序，再按长度 2、4、8… 合并两个排名；
- 每轮把「第二关键字 + 第一关键字」做两趟计数排序，单轮 $O(n)$；
- 排名互不相同就结束，总轮数 $O(\log n)$；
- `height[i] = LCP(sa[i-1], sa[i])` 用 Kasai 算法线性求出。

## 为什么选倍增而不是 SA-IS

倍增常数小、代码短、容易调，$n \le 10^6$ 时实测约 0.3s；SA-IS 虽然是 $O(n)$，但实现长得多，作为模板性价比不高。

## 复杂度

- 时间 $O(n\log n)$，空间 $O(n)$。

## 使用与易错点

- `build_sa(s, n)` 的 `s` 是 1-based 字符数组，`sa[1..n]` 也是 1-based；
- 字符按 ASCII 比较，大小写敏感；字符集超过 256 时把初始 `m` 调大；
- `build_height` 必须在 `build_sa` 之后调用；
- 多测重新调用即可，内部会覆盖用到的数组，不需要手动清空。

## 常见应用

- 两个后缀的 LCP = $\min(height[rk[i]+1..rk[j]])$，可配 ST 表或并查集离线；
- 本质不同子串数 = $\frac{n(n+1)}{2} - \sum height[i]$；
- 最长重复子串（可重叠 / 不可重叠）、多串拼接求公共子串。
