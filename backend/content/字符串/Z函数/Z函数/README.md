Z 函数：`z[i]` 表示字符串 $s$ 与它从 $i$ 开始的后缀的最长公共前缀长度，线性时间求出全部值。

## 核心思想

- 维护当前最靠右的匹配段 $[l, r]$，表示 $s[l..r] = s[0..r-l]$；
- 若 $i \le r$，先继承 $\min(r-i+1, z[i-l])$，这一段不用重新比；
- 再从继承来的长度继续暴力往后扩展；
- 扩展后更新 $[l, r]$，每个字符最多被扩展一次，总复杂度 $O(n)$。

## 复杂度

- 时间 $O(n)$，空间 $O(n)$。

## 使用与易错点

- 字符串与 `z[]` 都是 0-based，`z[0] = n`；
- 静态数组开到 `maxn = 1e6 + 5`，更长的串请换成 `vector<int>`；
- 与 KMP 的 `next` 数组不同：`z` 描述的是「后缀与原串」的 LCP，`next` 描述的是「前缀与后缀」的重合；
- 多测直接重新调用即可，内部会覆盖每一位。

## 常见应用

- 字符串匹配：把模式串、分隔符、文本拼起来求 Z，`z[i] == |模式串|` 的位置就是匹配点；
- 求最小循环节：若 `i + z[i] == n` 且 `n % i == 0`，则 `i` 是一个周期；
- 求每个后缀与全串的 LCP、统计相同前缀的出现次数。
