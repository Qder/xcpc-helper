【类型附录：数学】
本模板是数论或数学算法。除通用要求外，额外遵守：

1. 筛法：画 2..N 的数格，被划掉的变灰，当前素数 var(--accent)，当前筛掉的倍数 var(--warn)；N ≤ 60。
2. 快速幂/gcd/扩展欧几里得：用表格列出每步的变量值（a、b、结果、指数的二进制位），不用图。
3. 每帧存所有变量的当前值；note 写出算式，例如 "b 的当前位为 1，res = res * a mod p = 3 * 7 mod 11 = 10"。
4. FFT/NTT 之类过程太长的，只演示一个 n=8 的小例子，蝴蝶操作逐层一帧。
5. 线性筛、埃氏筛必须按【模板代码】的循环顺序画，不要换成另一种筛法。
