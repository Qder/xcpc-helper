【类型附录：字符串】
本模板是字符串算法。除通用要求外，额外遵守：

1. 把文本串和模式串上下对齐成两行字符格；模式串按当前对齐偏移平移。
2. 匹配成功的字符 var(--ok)，失配的字符 var(--warn)，当前比较的字符 var(--accent)。同时用对勾/叉号或下划线，不能只靠颜色。
3. KMP 要同时展示 next/fail 数组，并在失配时显示跳转到 next[j] 的过程。
4. 哈希类要展示当前窗口哈希值和模式哈希值，并标出冲突时的逐字符校验。
5. 输入：两行字符串；文本串 ≤ 24 字符，模式串 ≤ 8 字符。
6. 构建 next/fail 的预处理阶段单独占若干帧，不要和匹配阶段混在一起。
7. note 写出比较的下标与字符，例如「s[i]=a 与 p[j]=b 失配，j 跳到 next[j-1]=1」。
