【类型附录：操作序列】
适用于并查集、堆、树状数组、单调栈/队列等。除通用要求外，额外遵守：

1. 输入是操作列表，每行一个，如 "union 1 2"、"push 5"、"query 3 7"。
2. 每次操作拆成几帧：开始 → 关键中间步 → 结束，结束帧要显示操作结果。
3. 并查集：同时画数组 fa[] 和森林（用 layoutTree）；路径压缩单独成帧，不得省略。
4. 堆：上方画树形（下标 i 的 2i、2i+1 作为 left/right，可用 layoutBinary 的堆下标版本），下方画数组。
5. 树状数组：画原数组和 tree 数组，标出 i += lowbit(i) 的跳转链。
6. 操作数 ≤ 15。
7. note 写出操作与变量，例如「find(4)：fa[4]=2，尚未压缩；递归到 fa[2]=2」。
