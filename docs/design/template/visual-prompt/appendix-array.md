【类型附录：数组/DP】
本模板是数组、DP、二分或双指针。除通用要求外，额外遵守：

1. 一维用横向格子条，二维用表格；每格显示数值，下标写在格子上方。
2. 每帧存 dp 数组的完整拷贝（二维用 map(r => r.slice())）。
3. 颜色：正在写入的格子 var(--accent)；本次转移依赖的格子 var(--warn)；已计算的 var(--ok)。不能只靠颜色：当前格加粗边框，依赖格可用虚框或角标。
4. 转移步骤的 note 要写出公式和代入值，例如 "dp[i][j] = max(dp[i-1][j], dp[i-1][j-w]+v) = max(3, 2+4) = 6"。
5. 输入规模：一维 ≤ 16，二维 ≤ 8×12。用 MAX_N 与 parseInput 卡住。
6. 二分/双指针在格子条上用箭头或标记画出 l、r、mid、i、j 指针，指针重合时合并显示。
7. 滚动数组、恰好装满、方案数等模板特有写法必须按【模板代码】演示，不要改成另一份教材实现。
